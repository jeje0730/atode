# あとで。

SNSやWebで見つけた「いつか」を行動につなげる、Android / iOS向けFlutterアプリです。

## 実装済み

- URL・タイトル・画像URL・カテゴリー・メモの登録、編集、削除
- キーワード、カテゴリー、完了状態による検索と絞り込み
- 「行った」「観た」「買った」「読んだ」「興味なし」の状態管理
- 最近の保存と、7日以上見返していない未完了アイテムの再発見
- 予算・時間・気分・同行者による簡易提案。未登録の条件は確認が必要と明示
- SQLiteによる端末内保存、外部ブラウザーで保存元を開く
- Android共有メニューからURL・共有タイトル・文章を受信（終了中／起動中に対応）。複数URLや編集中に届いた共有は順番に表示
- 共有タイトルがない場合のページタイトル自動取得、手動での再取得（8秒でタイムアウト、取得失敗時は手入力）
- 最後に保存したアイテムのカテゴリーを初期値に設定（初回は「その他」）
- 同一URLの重複確認。utm系・igsh等の追跡情報とフラグメントを除いて比較し、別保存には確認が必要
- 共有時にページのタイトル・画像（Open Graph / Twitter Card）を自動取得。保存画面でプレビューし、手動取得・画像URL修正も可能。取得・読み込み失敗時は代替アイコンを表示
- 保存一覧の「新しい順／古い順」、星ボタンでのお気に入り登録・解除と絞り込み。お気に入りはSQLiteに保持し、既存データは自動移行
- 提案カードに予算・時間・気分・同行者の一致理由を表示。情報不足の条件は「確認が必要」と表示
- 詳細画面にカテゴリー別の完了ボタン（行った／買った／観た／読んだ／完了）、完了日記録、「未完了に戻す」と操作直後の取り消し
- 「完了履歴」タブに現在完了している保存を日付ごとに表示。未完了・興味なしは含めず、過去の完了日不明の保存は「完了日の記録なし」と表示
- ヘッダーのバックアップボタンからJSONの書き出し・復元。復元前に件数・先頭5件を確認し、既存のID・URLと重複しない保存だけ一括追加
- メールアドレス・パスワード認証の接続コードとアカウント画面（新規登録、メール確認、ログイン、再設定、ログアウト）。有効化にはSupabaseの接続設定が必要
- ゲスト／アカウント別のSQLite、確認付きゲストデータ引き継ぎ、保護領域へのセッション保存
- タブ切り替えは左右のスライドアニメーション。横スワイプにも対応し、検索条件・入力・スクロール位置を保持。端末のアニメーション抑制設定にも対応

## ログインを有効にする

現在は認証サービス未接続です。[接続手順](doc/auth_setup.md)に従い、SupabaseのProject URLと公開キーを`config/auth.json`に設定して、`flutter run --dart-define-from-file=config/auth.json`で起動します。設定なしではゲストとして利用できます。

## バックアップ・機種変更

1. 右上の「バックアップ・復元」ボタンを開き、「バックアップを保存」を押します。
2. スマホの「ダウンロード」や「ファイル」など、アプリの外に保存してください。
3. 機種変更後は保存したJSONファイルを新しいスマホに移し、このアプリで「ファイルから復元」を選択します。
4. 追加件数・重複件数・先頭5件の内容を確認して「追加して復元」を押します。

メモ・お気に入り・完了日も復元できます。画像はURLのみで、画像ファイルは含みません。現在の保存は削除・上書きせず、IDまたはURLが一致するものは現在のデータを優先してスキップします。復元は10MB・10,000件まで。途中でDBへの保存が失敗した場合は、その復元操作全体を取り消します。バックアップは暗号化されないJSONです。保存先と共有相手に注意してください。自動バックアップ・クラウド同期はまだありません。ログインは認証サービスの接続設定後に利用できます。

Androidエミュレーターで標準ファイル選択画面を使ったDownloadsへの保存、JSON選択、復元前確認、1件の復元、お気に入り・完了状態の引き継ぎを確認しました。

## 起動

Flutter 3.41 / Dart 3.11で検証。Android端末またはエミュレーターを接続して実行します。

```sh
flutter pub get
flutter run
```

```sh
flutter analyze
flutter test
flutter build apk --debug
```

iOSは14.0以上を対象とし、ビルドにはmacOSとXcodeが必要です。`flutter run`でiOSシミュレーターを指定するか、Xcodeで`ios/Runner.xcworkspace`を開いて署名を設定してください。iOSでの動作は未検証です。

## 構成

- `lib/main.dart`: ホーム、保存一覧、提案、登録・編集、詳細
- `lib/data.dart`: データモデル、SQLite永続化、提案の条件判定
- `lib/sharing.dart`: Android共有受信、URL抽出・比較、ページタイトル取得
- `lib/backup.dart` / `lib/backup_screen.dart`: ファイル入出力、バックアップ検証、復元確認画面
- `lib/auth.dart` / `lib/account_screen.dart`: 認証サービス、セッション保存、ログイン・登録・再設定・アカウント画面
- `test/widget_test.dart`: URL検証、提案ルール、保存後の再読み込み
- `test/persistence_test.dart`: SQLiteの再オープン後の保持、更新、削除
- `test/sharing_test.dart`: SNS形式のURL抽出、重複比較、共有画面の入力と保存確認
- `test/metadata_test.dart`: HTTPでのタイトル取得、取得失敗・タイトルなしの扱い
- `test/library_test.dart`: お気に入り操作・絞り込み、並び替え、提案理由
- `test/completion_test.dart`: 再発見から完了、取り消し、履歴、未完了への復帰、保存失敗時の扱い
- `test/backup_test.dart`: 全項目の往復、不正入力、重複判定、一括復元のロールバック、復元前確認とキャンセル
- `test/auth_test.dart`: 認証APIのHTTPモック、入力検証、セッション保存、登録・再設定、アカウント分離、ゲスト引き継ぎ
- `test/navigation_test.dart`: タブ移動後の検索・スクロール保持、横スワイプと連続タップ時のナビゲーション同期

## 完了を記録する

ホームの「忘れていたいつか」、保存一覧、提案の候補から詳細を開き、カテゴリーに合った完了ボタンを押します。完了履歴では完了日が新しい順に振り返れます。「未完了に戻す」と履歴から外れ、再び提案対象になります。完了日を持つアイテムのメモ編集・お気に入り変更では日付を保持します。履歴は現在の完了状態を振り返る画面で、同じアイテムを繰り返し実行した全イベントの記録ではありません。

初回は空の状態で起動します。予算・時間は保存時に任意登録でき、未登録なら提案で断定しません。SNSのタイトル・画像はサイトの取得制限・ログイン要否によって取得できない場合があり、手入力でも保存できます。画像はURL参照で、オフライン画像保存には未対応です。共有時の自動取得は入力済みのタイトルや画像を上書きしません。短縮URLと転送先URLの同一判定には未対応です。共有リスト、AI分類、iOSのShare Extension、通知、クラウド同期は未実装です。ログインには認証サービスの接続設定が必要です。データは端末内のみで、アプリのアンインストールで削除されます。画像は通信可能なHTTPS URLを推奨します。

## Androidで共有を試す

TikTok・Instagram等の投稿から「共有」→「その他」等でOSの共有メニューを開き、「あとで。」を選択します。URLと共有された文章を確認し、タイトル・カテゴリーを調整して保存します。共有元がテキストのURLを渡すことが前提で、動画・画像ファイルのみの共有には対応していません。

検証済み: 静的解析、36件の自動テスト、AndroidデバッグAPKビルド。テストにはv1/v2の保存データを維持したv3への移行、お気に入り・完了日の再読み込み、一覧の並び替え・絞り込み、画像URLの相対パス・リダイレクト解決、提案理由、再発見から完了・履歴表示・取り消し、保存失敗時の扱いを含みます。エミュレーターで終了中／起動中のACTION_SEND、編集中の次の共有の待機、保存、追跡パラメーターが違う同一URLの重複確認を検証しました。TikTok・Instagramの実アプリからの共有と物理端末での動作は未検証です。
